# 经验沉淀与参考学习法

工作流不是一次写定的，而是靠**每次发布后的真实反馈**持续校准。本文讲三件事：如何把读者评论变成红队教材、如何把踩坑变成铁律、如何用暗线把单篇选题连成系列。

---

## 1. 读者反馈四级判定框架（Step 8 核心）

群发后 1-3 天巡查评论区，把每条反馈归入四级之一，逐条对账原文：

| 级别 | 特征 | 处理 |
|------|------|------|
| **① 事实错误级** | 读者指出文章事实前提有误 | 立刻查一手信源核实；若属实 → 发勘误/修正版并敢认错；若读者错 → 用信源软回应，不公开认错 |
| **② 表述模糊级** | 事实没错但措辞让人误读 | 评论区软澄清（明确概念边界），未来类似话题在写作设计加「措辞精度」检查 |
| **③ 纯情绪噪音级** | 零论点零证据（如「瞎写一通」） | 不理会 |
| **④ 同构盟友级** | 读者用自己话复述了核心观点（常带情绪黑话） | 可互动借力，帮扩散 |

**输出**：每次巡查形成《反馈对账笔记》，沉淀为红队审查教材（下篇写类似主题时主动规避已被杠过的点）。

---

## 2. 踩坑 → 铁律

每条历史错误都应升级为可执行的规则，而非停留在「下次注意」：

- **错误 → 规则**示例：微信不支持 `<ul>/<li>` → 固化进 8 项兼容检查第 5 条；标题超 64 字节 → 标题铁律锁 15 字内；中文乱码 → `ensure_ascii=False + UTF-8` 写进推送脚本。
- **记录格式**：日期 / 错误 / 教训，便于回溯与 ADLR 审查（见 `docs/04`）。
- **原则**：铁律属「质量底线约束」，应保持固定，不为「辅助不限制」而弱化。

---

## 3. 暗线连续剧选题法

单篇选题容易散。用「连续剧」把相关选题连成系列，既降低每篇的铺垫成本，又培养读者追更习惯：

- 每篇标注「第 N 集」与系列主线（如「AI 安全连续剧」）。
- 主线按风险演进递进（如：框架裸奔 → 信错人 → 自己人开枪 → 看门人换 AI → 开源力量救场 → 风险近端化）。
- 新篇开头用浅橙卡一句话接上集，中部展开本集，结尾埋下集钩子。
- **注意一致性**：集数、事件归属必须前后统一（曾经出现过「第 3 集」与「第 5 集」冲突的硬伤，靠红队逻辑维度堵住，见 `docs/02` §5.2）。

---

## 4. 红队教材沉淀

每次对抗式审查（见 `docs/02` §5）的发现，都应回流到两处：

1. **写作设计阶段**：已被杠过的角度 / 表述，下篇提前堵（读者反驳点维度）。
2. **工作流文档**：重复出现的问题升级为铁律或检查项（配合 ADLR，见 `docs/04`）。

> 闭环本质：读者评论（最高质量红队）→ 对账笔记 → 写作设计堵漏 + 文档铁律固化 → 下篇质量提升。这条链路让工作流**越跑越聪明**，而不是每次从零开始。
