## 一、品牌定位声明

### 一句话定位

**用从业者的眼睛看 AI，用普通人的话说给从业者听。**

### 完整定位

> 「六一的AI人生记录仪」是 AI/智能体/AI 安全领域的第一人称深度内容平台。
> 作者以 AI 从业者的真实视角，记录 AI 行业每天发生什么、意味着什么、我们该怎么做。
> 不说正确的废话，不跟风喊口号——给事实、给分析、给立场。

### 目标读者画像

| 维度 | 描述 |
|------|------|
| **核心读者** | AI 从业者（研发/产品/安全/商业化），25-40岁，一二线城市 |
| **延伸读者** | 技术管理者、投资人、对 AI 有深度兴趣的跨界从业者 |
| **读者诉求** | 不看流水账新闻，要有人帮他把事件嚼碎了讲清楚"意味着什么" |
| **阅读场景** | 通勤路上、午休、晚间休息——碎片时间里的深度阅读 |

## 二、核心价值主张

### 我们提供什么（Value Proposition）

| 价值维度 | 具体承诺 | 交付方式 |
|----------|---------|---------|
| **信息降噪** | 每天 AI 圈几百条消息，只挑最该关注的 1 条深挖 | 日更1篇，不注水 |
| **认知框架** | 不止告诉读者"发生了什么"，更回答"为什么重要" | 每篇必给个人观点 |
| **跨界连接** | 用安全带类比 AI 安全、用汽车史类比技术普及 | 跨领域类比前置 |
| **行动指引** | 看完不只是"涨知识"，而是"我该关注什么/怎么做" | 文末总结+思考延伸 |

### 品牌承诺

> **每天一篇，篇篇有观点。** 不写没立场的行业综述，不发没有个人判断的信息搬运。

## 四、语言风格指南

### 核心原则：第一人称对话式

**不是写文章，是跟一个懂行的朋友聊天。**

### 句式规范

| 推荐 ✅ | 禁止 ❌ | 原因 |
|---------|---------|------|
| "我读完发现……" | "值得注意的是……" | 真人表达 vs AI 套路 |
| "先说结论……" | "综上所述……" | 直接 vs 套话 |
| "等等，这里有个问题" | "然而，不容忽视的是……" | 对话感 vs 论文腔 |
| "你猜怎么着？" | "由此可见……" | 互动感 vs 生硬过渡 |
| 短句+破折号 | 长句+逗号嵌套 | 呼吸感 vs 窒息感 |

### 禁用词清单（绝对不出现在正文中）

> 值得一提的是 / 不容忽视的是 / 综上所述 / 由此可见 / 总而言之 / 不难发现 / 众所周知 / 毋庸置疑 / 显而易见 / 不言而喻 / 诚然 / 毋庸置疑

### 推荐表达方式

| 场景 | 推荐写法 |
|------|---------|
| 引出观点 | "我的看法是……" / "说实话……" / "直接点说……" |
| 转折 | "但问题是……" / "等等，这里不对劲……" / "事情没这么简单" |
| 强调 | 短句独立成段 / 破折号 / 加粗 |
| 引入数据 | "数字说话：……" / "先看一组数据" |
| 总结 | "所以呢？" / "回到开头那个问题" / "一句话总结" |

### 标点偏好

- **破折号**：用于补充说明、语气转折（每篇控制在 20-30 个，不泛滥）
- **省略号**：少用，不超过 3 次/篇
- **引号**：引用原文、概念术语必须加引号
- **感叹号**：每篇不超过 2 个，克制使用

### 段落长度

- 正文段落：2-4 句为宜，最多不超过 6 句
- 强调段落：独立成句，前后留白
- 长段落必须拆分——微信屏幕上一屏超过 5 行就是"墙"

## 六、内容支柱与边界

### 四大内容支柱

| 支柱 | 占比 | 关键词 | 示例选题 |
|------|------|--------|---------|
| **AI与大模型** | 35% | 模型能力/技术演进/行业趋势 | "为什么 GPT-5 不是突破" |
| **AI智能体** | 25% | Agent/自动化/工作流 | "AI Agent 安全之城墙在塌" |
| **AI安全与治理** | 20% | 漏洞/合规/政策/伦理 | "Prompt Injection 的完整攻击链" |
| **AI产品与应用** | 20% | 商业化/落地场景/用户体验 | "Claude Code 到底改变了什么" |

### 内容红线（绝不触碰）

| ❌ 不写 | 原因 |
|---------|------|
| 纯产品软文/推广 | 损伤公信力 |
| 未经证实的爆料/谣言 | 事实是底线 |
| 纯情绪煽动（没有事实支撑的观点） | 有观点，但必须有依据 |
| 翻译搬运外网文章 | 不做信息搬运工 |
| 泛科技类"AI将改变一切" | 太宽泛，没有价值密度 |
| 政治敏感话题 | 合规红线 |

### 内容优先级（选题决策时参考）

```
有独家视角 > 有反差角度 > 有跨界连接 > 有深度分析 > 有热点时效 > 纯信息汇总
```

## 十、品牌演进路线

### 短期（1-3个月）：稳定输出，建立认知

- [ ] 连续 90 天日更不断
- [ ] 视觉一致性 100%（每篇 14 条自检全过）
- [ ] 产出 3-5 篇万阅读爆文
- [ ] 建立读者预期："每天打开都能看到一篇有质量的"

### 中期（3-6个月）：IP辨识度

- [ ] 读者看到排版就知道是"六一"（不看名字也认得出来）
- [ ] 固定栏目/系列化内容（如"A1 Agent安全指南"系列）
- [ ] 选题数据库成型，数据驱动选题

### 长期（6-12个月）：行业影响力

- [ ] 成为 AI 安全领域有话语权的个人 IP
- [ ] 内容被行业引用/转载
- [ ] 建立读者社群（微信群/知识星球）
